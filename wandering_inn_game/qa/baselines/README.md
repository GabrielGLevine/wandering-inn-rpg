# qa/baselines/ — frozen inputs the prose and dialogue gates read

These are gate fixtures, not documentation. They moved here from `docs/` on
2026-08-11 because `docs/` is for references, records, and state — a pinned
corpus snapshot that a script diffs against is neither.

## `prose/` — the #397 prose-naturalization pins
Read by `qa/scripts/extract_prose.py` (`DOCS` constant). `verify-untouched`
runs in `scripts/preflight.sh`, so these files gate every wave close.

| File | What | Authored by |
|---|---|---|
| `inventory.jsonl` | Frozen pre-pass baseline of every prose string | Generated once; never moves |
| `holdout.json` | The Phase 5 control group + declared exclusions | Generated, then hand-amended |
| `protected-keeps.json` | Ruled keeps pinned to `{file, field_path, exact_text}` | Generated from the petitions |
| `protected-keeps-extra.json` | Lane-added keeps folded at #397 integration | Hand-authored |
| `classification-overrides.json` | Hand-audit corrections to auto-classification | Hand-authored |
| `landmark-registry.json` | Every ruled landmark string plus its grant | Regenerated by `landmarks` |
| `inventory-commentary.md` | Frozen analysis appended verbatim by `all` | Hand-authored |
| `keeps-petitions/` | The lane petitions the keeps answer to (provenance) | Hand-authored |

Everything else `extract_prose.py all` writes here (classified inventories,
blind samples, phase reports, worklists, pin-deltas) is a derivative and is
gitignored — regenerate it rather than committing it.

## `dialogue-voice/` — the #388 voice-pass skeleton snapshots
Read by `qa/scripts/dialogue_voice_gate.py --baseline`.

- `lines/` — dialogue-graph skeletons (`check --baseline qa/baselines/dialogue-voice/lines`)
- `maps/` — map prose skeletons (`check --maps --baseline qa/baselines/dialogue-voice/maps`)

The gate proves structure is byte-stable while prose changes. `maps/` has
drifted since the pass (later waves added entities), so `--maps` currently
hard-fails on structure until it is re-snapshotted; `lines/` is clean. Neither
runs in `preflight.sh` — invoke them when a wave edits dialogue or map prose.
