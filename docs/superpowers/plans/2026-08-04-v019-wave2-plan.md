## 1. Thesis

**v0.19 is the wave where the world answers the hand:** every verb the
player aims at the world lands on something real and visibly resolves,
and every place the game currently swallows input without answering
gets repaired to the same standard.

Build it forward — the property layer (#387) plus the martial verbs
(#380–#383) plus the feedback tell layer (#335). Repair it backward —
the eight blind-playtest findings (#372–#379), each of which is the same
defect stated a different way: an input the game takes and does not
answer. The through-line is attested in the issues' own cross-references
(the #348 spec's K5 gate binds slice 2 to #335; #380's "the mage makes
the ice, the martial crosses it"; #381 "the row that justifies slice 2";
#374→#372 "these two land together").

## 4. Phases

**Phase 0 — substrate.** Two parallel worktrees on strictly disjoint
files; both merge to main before phase 1 opens. This is the bet that
makes six-wide fan-out safe: every `src/core/**` edit in the wave lands
once, under the full unit bar. After phase 0, `src/core` is FROZEN —
any phase-1 lane discovering a sim need STOPS and reports (a one-hunk
S0.1 patch lane is cheaper than a seam reversal, which is a logged
incident class).

**Phase 1 — six concurrent lanes,** each in its own worktree. No
cross-lane waits; the only sequencing is inside lanes and at declared
handoffs.

**Phase 2 — anchored merge train,** controller-run:
**L6 → L1 → L3 → L4 → L2 → L5.** L6 first (standard-setter: its
stratified envelope runs against siblings pre-merge); L4 before L2 (the
ice tile must be on the tree before the [Ice Floor] grant merges — the
P1 hard order); L5 last (the feedback layer's windowed read happens once
on the composed tree). Then main-tree `--headless --import` (new image
assets), full sweep, all unit suites, balance batch, census slack check
*before* regen, dialogue voice gate, then the full wi-machine-playtest
pass.

**Phase 3 — close.** Freeze step-0, CHOICE-LOG block, five prepared
playtest states, split issues FILED (not "deferred"), tag v0.19.0,
Release/Pages watch, HANDOFF rewrite, K5 friend playtest scheduled as
the post-tag event.

## 7. Risk register

1. **A phase-1 lane needs a sim edit phase 0 missed.** `src/core` is a
   STOP trigger in every phase-1 brief; the remedy is a one-hunk S0.1
   patch lane, never a seam reversal.
2. **Composed-census 15.0% ceiling.** #378 + #380 + #383 all append to
   items.json; headroom after W5's trim was 470.9 chars. Slack check and
   comment-trim are named pre-merge steps, before regen.
3. **Prose QA-coupling.** #372, #378, #379, and S0a's refusal cells are
   all prose. Voice gate plus pin-sync per lane on owned scripts, and
   once more on the composed tree.
4. **Pinned seeds flip under combat-adjacent data.** [Bar Fighting]'s
   `next_fight` item and the classes.json grants can move canonical
   outcomes. The AGENTS.md seed table is the only seed source; guessed
   seeds are a named failure mode.
5. **Merge-train mechanics.** Commit success reads from rc + `git log`,
   never hook chatter (a swallowed BLOCK silently lost three commits
   last wave). Main-tree `--import` after the train pull, before the
   re-gate, because this train carries new image assets. Checks table
   read as its own step.
6. **The ice tile misses.** Pre-declared contingency: pull the [Ice
   Floor] grant row from L2's merge (one row, inert without it). The
   martial five ship regardless.
7. **Silhouette fixes that don't fix.** Both #376 and #378-art exist
   because the last answer (tint) didn't read. The cold-reader test —
   render at 1x side by side, ask which you sleep in — is the lane's
   acceptance gate, not the windowed capture itself.
8. **`state_set` is one-way and save-persisted.** A wrong row is
   durable world corruption in a save, not a toast. S0a's reviewer lens
   B is a save round-trip adversary.
