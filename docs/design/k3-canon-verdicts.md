Clear action-verb failures beyond observe: none — the rest of the kit is
noun/noun-phrase shaped ([Basic Cleaning], [Basic Cooking], [Power
Strike], [Quick Cast]...; gerunds and noun phrases read as Skill names,
not bare imperatives). Borderline, flag-not-rename: none identified.
