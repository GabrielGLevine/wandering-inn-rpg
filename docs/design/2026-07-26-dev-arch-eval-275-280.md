# Dev-architecture wave adjudication: #275–#280 (2026-07-26)

Ruling on the six engine-inspired dev-architecture proposals (hearth: #275/#276/#277,
GDevelop: #278/#279, OpenGame: #280). Provenance: 13-agent evidence workflow — one
evaluator per issue verifying every repo claim at file:line, one adversarial skeptic
re-reading each evaluation's load-bearing citations, plus a cross-cutting infra map.
Every eval↔skeptic verdict pair converged. This doc is the controller synthesis: the
holistic plan, the per-issue adjudicated scopes, and the danger list a dispatched
implementer will not discover alone.

**Meta-verdict:** all six ideas are directionally sound, and all six over-specified
mechanism that duplicates shipped infrastructure. The adopted scopes below are the
verified *deltas* over what already exists. Five adopt-modified, one defer.

| # | Proposal | Verdict | Adjudicated size | Codex-dispatchable |
|---|---|---|---|---|
| 276 | Engine-free data lint | adopt-modified | S | yes |
| 277 | Placeholder assets | adopt-modified (reshaped hard) | S | yes |
| 278 | Live data reload | adopt-modified (reshaped hard) | S | yes |
| 275 | Semantic data diff | adopt-modified | M | yes |
| 279 | Dev debug overlay | adopt-modified | M | yes |
| 280 | Scored FEEL bench | **defer** (revival shape below) | M | no |

Sequencing constraint (stands, every agent confirmed it): all of this rides
**behind or beside #269/#270**, the READY-START-THERE v0.14 content specs. Dev-infra

## 1. Cross-cutting findings (what makes the plan holistic)

**F1 — Shared Python data layer already exists in triplicate; extract it.**
`generate_shipped_ids.py:183-196` (`load_scene()`, the pure-Python mirror of
`WISceneCatalog.compose()` with the exact contract documented), `generate_postings.py`
(same contract copied), and `derive_qa_surfaces.py:113-120` (`_known_maps`) are three
hand-synced copies; `generate_shipped_ids.py` also carries the counter-producer census
(:127-180) and `STRUCTURAL_LITERALS` (:94-105). Phase 0 extracts one shared helper
(`wandering_inn_game/scripts/wi_data_lib.py`) that #276 and #275 import. This
*demotes* the biggest risk logged against both issues ("another composition
implementation that can drift") into a net consolidation — strictly better than HEAD.

**F2 — `derive_qa_surfaces.py --touching` has a silent-empty hole.** `cmd_touching`
(:272-350) recognizes qa/scripts, qa/fixtures, data/dialogue/, data/maps/, and
skills.json — but `--touching data/portals.json` (also quests/classes/acts/bounties/
combatants) prints **nothing, exit 0**, even though `qa/manifest.json` already tags
the right carriers (e.g. `portals` systems tag on all 7 portal canonicals). #275's
re-pin callout composes on this, and the silent empty is a live footgun for every
current caller. Phase 0 fix: route monolithic data paths → manifest systems tags
(~10 lines) + never-silent output.

**F3 — Dev-only gating idiom: there are no export feature tags; don't invent any.**
All four export presets have `custom_features=""`. The proven patterns are
(a) `OS.is_debug_build()` — hides the Playtest States title row
(`title_screen.gd:410`), release exports use `--export-release`; and
(b) ships-inert-behind-arg — TestDriver is an always-shipped autoload
(`project.godot:32`) that self-deactivates without `--qa-script`
(`test_driver.gd:67-69`). #278/#279 both cited each other's nonexistent gating
(vaporware chain); both now cite these two idioms instead. #279 establishes the
`is_debug_build` surface; #278 needs no keybind at all.

**F4 — The only correct home for a "placeholders never ship" gate is the release.yml
itch job.** `leak_check.sh` and any edit-time lint run on every push/PR — wiring the
gate there would ban placeholders from main, contradicting the policy's own intent.
The gate: post-overlay, **disk-only** scan (never honor the `assets_manifest.json`
relaxation — that also catches the manifest-vs-bundle silent-ship gap, a failure mode
nothing covers today) of every path referenced by sprites.json + audio.json, scoped
to the `release` itch job only — desktop-exports/steampipe ship the fallback tree by
design and are exempt. A HEAD scan shows zero missing paths: this lands green, a
ratchet converting a process-held invariant into a mechanism (QA-first doctrine).

**F5 — CI topology: ci.yml has no `needs:` edges.** The "leak-check runs first"
comment is aspirational; jobs are parallel and sweep jobs boot Godot before
`ci_sweep.sh` runs. So the #276 lint must land twice: in `ci_sweep.sh` pre-flight
(after the `derive_qa_surfaces --check` call at :251-254 — same FATAL shape) for the
local short-circuit, and as a step in the leak-check job (ci.yml:60-78, already four
python3 checks, no setup) for any CI-side pre-Godot signal.

**F6 — Much of what the issues want already ships.** Missing sprite sheets already
synthesize deterministic frame-sized placeholder textures at runtime
(`sprite_registry.gd:135-140,171-219`; N-frame animations fakeable via region on a
nonexistent sheet, proven at `test_sprite_registry.gd:82-85`); missing audio is
silent-fallback (`wi_audio.gd:95-104`); the swap queue is VISUAL-LOG + the
`test_sprite_registry.gd:40-60` drained-ids pin; pause-menu Save→Load already
rebuilds the sim from fresh disk JSON (`game.gd:112-124` → `_make_sim` :193-226);
`events.jsonl` live-writes in every non-web session (`observable_bus.gd:8-10`);
VISUAL-LOG demonstrably catches acceptance drift qualitatively (:35-39, the GH#28
dark-arena catch). The adopted scopes are what's genuinely left.

## 2. Adjudicated per-issue scopes

### #276 — data lint (S; **phase 1, the foundation**)
Trimmed to checks the Godot suites do NOT already own:
1. JSON well-formedness across `data/**` — net-new mainly for maps/dialogue/remaining
   catalogs (`derive_qa_surfaces --check` already json.loads skills.json + manifest +
   fixtures + QA scripts engine-free on every sweep).
2. Map in-grid bounds for `blocked` cells and entity cells — the realest gap (a
   typo'd cell is caught today only if a canonical happens to pin it; the b10
   out-of-grid saga is the lived proof).
3. Portal destination map/cell existence — static-only today; behaviorally covered
   by six canonicals, so this buys *earlier* detection, sold as such.
4. Minimal required-key presence per domain (dialogue node speaker/text, options'
   goto targets in-graph, sprites animations shape).
5. Donated from #275's motivation: `portal_menu_when` must wrap `requires` — a state
   lint rule that catches the vacuously-true shape **already shipped** at
   `invrisil_boulevard.json:903` (a diff tool structurally never sees it).

**Dropped:** the cross-file-ID tier and counter-hygiene tier — duplicated (up to
three-layer drift) in `test_content.gd` (producer registry :125-147 + ~15 unproduced
asserts), `test_combat_data.gd:69-125`, `test_reachability.gd` (consumed-vs-produced
+ allowlist). Read-side counter hygiene is covered twice; produced-but-never-read is
deliberately unpoliced (toast-only counters are legitimate).

Builds on the F1 shared loader. Wire per F5. Skill wording (Fable-only edit):
lint = pre-check, **never** a substitute for the Godot gates — the
verification-boundary failure mode wi-delegating-to-codex catalogs.

### #277 — placeholders → ship-gate ratchet + audio pending-slots (S; phase 2)
The issue's central mechanism is wrong against the real code: committed placeholder
PNGs would *disable* `is_fallback_sheet` tracking (flipping
`test_sprite_registry.gd:27-30`'s relaxed assert to exact-count), conflate the
licensing-fallback channel with the never-made-art channel, and add .import churn;
`data/placeholders.json` duplicates state fully derivable from a scan. Adopted scope:
1. **Release ship gate** per F4 (~30 lines in release.yml itch job).
2. **Audio pending-slot mechanism** — the WAV-generator idea dies on
   `test_audio_data.gd:290-291` (music must be .ogg) and :344-345 (ambience on-disk
   .ogg, manifest relaxation explicitly refused). Instead: one committed silent-OGG
   template copied per pending slot, or a schema-level `pending` marker — either way
   enforcement is the same release scan (pending rows are missing post-overlay, so
   the gate catches them for free). Unblocks #195-adjacent slot wiring.
3. Optional polish: ~20 lines in `sprite_registry._placeholder_texture` to louden
   the synthesized stand-in + stamp the entity id (currently muted flat color +
   1px border), so FEEL passes can't mistake it. Fidelity doctrine untouched —
   these never ship (the gate is what makes that mechanical).

### #278 — live reload → four-cache fix + reload_data step (S; phase 2)
Save→Load already reloads dialogue/balance/quests/items/classes fresh from disk.
What's actually stale: **four static caches** — `WISceneCatalog._cache`
(`scene_catalog.gd:7-13`; `reset()` exists, zero callers), and no-reset-at-all on
`WISpriteRegistry` (`sprite_registry.gd:4-6`), `WIAtmosphere._moods_cache`
(`atmosphere.gd:16`), `WIBoardRenderer._moods_cache` (`board_renderer.gd:112`).
Scope:
1. `WISceneCatalog.reset()` **before `_make_sim`** (in `load_slot` /
   `import_save_text` / `reset`) — see danger D1.
2. The three view-cache resets wired beside `WIDataRegistry.reset()` in the
   GAME_LOADED handler (`main.gd:403`).
3. A `reload_data` TestDriver match arm composing save+load — implementing the
   `save_manual`-style blocked-state refusal itself (danger D2), refusal emitting
   the existing toast idiom (`game.gd:105`) so agents observe it.
4. QA proof runs inside the documented detached-worktree protocol
   (`qa/MACHINE-PLAYTEST.md:21-31`) — no new isolation machinery.
5. wi-machine-playtest skill documents the edit→Save→Load workflow (Fable-only).

**Dropped:** dev keybind (TestDriver arg-gating suffices), data-dir override
plumbing (`qa_paths.gd` has none; loose-file runs only — meaningless in packed
exports, fine for the windowed dev use case). Out of scope, documented: reload
after id renames/removals is quietly-wrong, not refused (`save.gd:279-298`) —
value-tuning tool, not a migration tool.

### #275 — semantic data diff (M; phase 3, after F1+F2)
`scripts/data_diff.py`, two refs → per-domain markdown for PR bodies. Adjudications:
1. **Advisory only, never a required check.**
2. **Mandatory unsummarized-keys fallback** — every changed key not recognized by a
   domain summarizer is counted and listed. Without this the tool makes review
   *worse* for exactly the Sonnet-class sessions it serves (summary read instead of
   raw diff). Schema evolution is certain (#269 adds `present_when.guest` shapes).
3. Portal handling: **flag** portals.json/`portal_menu_when` deltas and name re-pin
   carriers via the F2-fixed `--touching` — never simulate menu order (menu is
   code-built, `interactions.gd:105`; simulating it duplicates game logic).
4. **Drop the combat-numerics domain** — `harness_shard_diff.sh` already gives the
   stronger behavioral before/after vs a git ref.
5. Scope honesty in the output header: the loudest callout (re-pin carriers) points
   at qa/ files outside the diffed data — the tool prompts re-pins, it cannot verify
   them.
Dialogue options are id-less array members — positional matching, stated as such
(reworded option = remove+add). `_comment` keys excluded (established discipline).
Fixture-pair unit tests per domain under `scripts/tests/` (existing unittest idiom);
dogfood on 2-3 merged data PRs.

### #279 — debug overlay (M; phase 4)
Read-only (verbatim guard), `OS.is_debug_build()`-gated, hosted in an
**autoload-owned root CanvasLayer** (layer above journal's 10) — which dissolves the
`_clear_ui_layers` survivor trap entirely (it iterates only Main's children,
`main.gd:292-309`) and gets boot-time ObservableBus connection free. Content:
- Map + player cell; **live `Game.sim.rng.state`** (public, `wi_game.gd:66`; the
  save system already reads it, `save.gd:56/324`) — NOT the SIM_INITIALIZED seed,
  which is constant 0 in human sessions and fires before the overlay could listen.
- Accomplishment counters + active quest beats — quest rows via the `WIQuests`
  seam (`quests.gd:21-37`; beats are derived, not in `snapshot()`).
- Rolling ~20-event tail via `domain_event` connection (TestDriver's own pattern),
  throttled once-per-frame.
- Save-slot status + last autosave trigger — recorded at `game.gd:84-90`'s
  `save_auto` call sites (two lines in the *autoload*, not the sim; doctrine clean).
- Anti-rot: render `snapshot()` keys generically + a curated highlight set, so new
  sim fields appear without hand-picking.
QA: `toggle_overlay` as a node-call step (per `drag_journal_body` precedent,
`test_driver.gd:184-208`) — no input-map change; human keybind lives in the
overlay's own `_unhandled_input`. Prove overlay fields against `assert_state` on the
same script. **The inverted verification emphasis (danger D4): captures are
full-window (`test_driver.gd:812`), so the real hazard is overlay-on contaminating
normal FEEL evidence — pin an overlay-hidden-by-default assertion into the canonical
FEEL scripts.** Consumers honestly scoped: itch/mobile human playtests never see it
(release builds); the payoff is local windowed sessions — mostly agent FEEL work and
prepared-save eye-gates, which is still the right audience.

### #280 — scored FEEL bench: DEFER
Three decisive, verbatim-grounded objections: (1) the issue's own acceptance bar
(±1 cross-session agreement per axis) **equals** its alarm threshold (≥1-point
drop) — the flag either false-fires or gets habitually dismissed; (2) cross-tier
judge stability (Fable-authored anchors scored by Sonnet-class judges later) is
unvalidated, and the ledger has no judge-tier field to control for it; (3) the
qualitative machinery already catches drift (VISUAL-LOG :35-39 caught the GH#28
dark-arena acceptance drift exactly as this issue fears nobody would). Front-loaded
calibration (two full ~50-shot scored rotations + a regression-branch test) is the
wrong spend against #269/#270 and interacts with open #140 capture noise.

**Revival shape (post-v0.14, recorded so it isn't relitigated):** first, add rubric
axes + written anchors directly to `MACHINE-PLAYTEST.md` and derive a shot-id
manifest via the existing `derive_qa_surfaces` generated-field + FATAL-drift idiom
(near-zero maintenance — the skeptic refuted "new hand-maintained artifact"). Only
after two milestone passes demonstrate anchor agreement: add `feel_scores.jsonl`
(+ judge-tier field) and the trend script with a **2-point-or-sustained-two-
milestones** alarm. Cost mitigation: seed-9 pixel-diff prefilter — score only shots
whose pixels changed since last milestone (byte-identity precedent already in
VISUAL-LOG :58).

## 4. Danger list (pin into every dispatch brief)

- **D1 (#278) Reset ordering:** `WISceneCatalog.reset()` in the GAME_LOADED handler
  is a bug, not a fix — `_make_sim` consumes the stale compose at `game.gd:119/:194`
  *before* GAME_LOADED emits at :123, while the rebuilt view reads fresh
  (`world.gd:662`) → sim blocking diverges from rendered map on the first post-edit
  Load, the project's worst failure class. Scene-catalog reset goes BEFORE
  `_make_sim`; only the three view caches belong in the handler.
- **D2 (#278) No guard where you'd expect one:** `save_auto` (`game.gd:93-100`) and
  `load_slot` (:112-124) carry NO blocked-state check — the refusal lives only in
  `save_manual` (:104) / `export_save_text` (:140). A naive reload_data composition
  silently drops combat state (WISave has no combat key) and teleports out of the
  fight. The step implements the check itself.
- **D3 (#277) Gate home + scan mode:** itch `release` job only (desktop/steampipe
  exempt by design); disk-only scan, never the manifest relaxation
  (`test_audio_data.gd:137-147` proves membership ≠ existence;
  `make_asset_bundle.sh:97-104` only warns).
- **D4 (#279) Evidence contamination:** full-window captures mean "no
  world-viewport contamination" is trivially true and the REAL risk is inverted —
  overlay-hidden-by-default must be asserted in canonical FEEL scripts.
- **D5 (#275) Summary-instead-of-diff:** without the unsummarized-keys fallback the
  tool is negative-value for weaker reviewers. Non-negotiable output contract.
- **D6 (#276) Lint-green ≠ validated:** skill wording must pin lint as pre-check;
  Godot gates remain the authority (verification-boundary doctrine).
- **D7 (all) Sequencing:** #269/#270 stay START-THERE; these are side-lane/downtime
  dispatches.
