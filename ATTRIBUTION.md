# Attribution

Art, audio, and other media in this repository and in official builds,
with their licenses and required credits. Community contributions are
added here as they merge (see `CONTRIBUTING-ASSETS.md`). The in-game
mirror of this file is the Settings → Credits panel
(`wandering_inn_game/data/credits.json`).

## Setting

The Wandering Inn is a web serial by **pirateaba**
(https://wanderinginn.com). This is an unofficial, unlicensed,
non-commercial fan project; setting, characters, and lore belong to
pirateaba. Read the story free at wanderinginn.com — and pre-order the
first book, *No Killing Goblins* (out August 12, 2026).

## Repository media

`wandering_inn_game/assets/LICENSES/` contains only the license/terms
files that shipped packs require us to redistribute. Assets whose
licenses do not permit redistribution are not present in this
repository; official builds add them from a private bundle, and the
public build uses fallback art (or silence) in their place.

## AI-generated assets

Several character sprites and props are AI-generated via

per its terms).
